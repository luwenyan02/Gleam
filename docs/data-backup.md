# 数据与备份

## 本地数据

拾光将账单、账户、分类、生活记录、附件和设置保存在当前设备。清除站点数据或卸载应用可能删除这些内容。

## `.skbak` 备份

- 完整备份包含业务数据和附件。
- 可选择口令加密；口令不会被拾光代为找回。
- 云备份与 AI 凭据始终从备份中剔除，恢复后需要重新配置。
- 恢复会先解析和验证文件，再要求用户确认。
- v3 备份包含普通账单的凭证关系、排序和缩略图，每张原图单独做 SHA-256 校验；仍兼容 v1/v2 旧备份，旧包的账单凭证关系按空集合恢复。
- v4 新增生活草稿和拾光周刊；v5 扩展生活 AI 原始会话、按消息照片引用与独立摘要建议。当前版本兼容 v1—v4，旧包缺少的新表会补为空。恢复后生活 AI 重新关闭，须再次同意发送。
- 图片缺失、大小或哈希不符、账单凭证关联损坏会在覆盖数据前拒绝。写入失败时整库事务回滚。

建议在升级、换机、大批量导入和批量删除前创建加密备份，并至少保留两份独立副本。

生活草稿也属于私密内容，照片内联保存在本地草稿与备份中。排除 AI 不等于从备份中删除；已收藏周刊因来源排除或删除而隐藏后，仍在本地备份内保留，需“清理这一期”才能删除归档。旧备份副本不会自动改写。升级前保留一份旧版本备份，不要直接用旧 APK 打开升级后的数据库。

## 生活 AI 与周刊

生活 AI 默认关闭。首次发送、重新打开会话、服务或模型变化以及新增照片时，先展示服务地址、模型与选定素材；同页同目标的后续纯文字可沿用本次授权。图片只随明确选择的当前消息发送，之后的纯文字不会再次上传历史照片。周刊只发送所选记录的文字、日期与用户填写的感受，不发送账单或照片。服务商的数据保留规则仍适用，关闭 AI 不会撤回已经到达服务方的请求。

“快速记录”关闭后保留本机草稿且不调用 AI；“和拾光聊聊”单独保存原始会话、未发送输入和摘要建议。只有用户在确认抽屉点击保存后才成为生活记录，AI 建议与用户原话分开保存，继续聊天不会自动覆盖用户编辑。会话照片保存为本地附件引用，备份不在正式会话里重复保存 base64。周刊按自然周生成，独立于财务月；只收藏用户确认的预览，不自动后台生成。更改原记录会标记周刊过时，删除或排除任一来源会隐藏整期旧内容。回访仅在生活页展示，可延期或忽略，不发送系统推送。

## 账单凭证

记账面板「更多」中可添加、预览、前移、替换和移除图片，每笔最多 9 张，仅接受 JPG、PNG、WebP，单张不超过 10 MB；超过 4000 万像素或不能解码的图片会被拒绝。图片仅随账单保存事务落库，取消草稿不写入，保存失败不残留图片。

软删除和恢复保留凭证；永久删除或移除图片时，仅回收没有其他账单、生活记录或 AI 素材引用的附件。导入前快照及撤销也包含凭证。Excel 不是完整备份，不承载图片。

Android 分享图片时先选择用途：「作为账单凭证」只加入本地草稿，不发给 AI；「AI 识别记账」使用用户已配置的识别服务。当前有记账草稿时，凭证追加到草稿，不覆盖已填写信息。

## Excel 导入导出

- 导入支持拾光格式、挖财 12 列格式，以及微信／支付宝导出的 CSV 或 Excel 账单。
- 导入分为预检、映射、确认和报告，不合法行会跳过并说明原因。
- 重复判断使用发生时间、类型、金额和账户等字段。
- 测试只能使用 `app/e2e/fixtures/` 中的虚构样例。

### 挖财字段映射

| 挖财字段 | 拾光处理 |
| --- | --- |
| 日期时间 | 记账时间，精确到分钟 |
| 类型 | 支出、收入、转账或借贷 |
| 类别 | `大类/小类` 按斜杠拆分；无斜杠时匹配现有分类 |
| 金额、币种 | 金额以整数分入库；外币折算信息保留在备注 |
| 收付账户 | 普通账单匹配账户；转账及双边借贷按正负金额识别转出与转入账户 |
| 收付款人 | 借贷采用单资金账户格式时，从“自己／对方”的双边金额识别应收应付账户；不建立独立对象 |
| 参与人 | 只将“自己”的份额入账，完整分摊说明保留在备注 |
| 标签、商家 | 匹配或新建对应标签与商家 |
| 属性、备注 | 报销状态按属性识别；退款跨文件导入时不保留原账单关联 |

导入前会展示预检和映射结果，只有用户确认后才写入数据库，并自动创建可撤销快照。

借贷的资金侧须为非应收应付账户，对方须为应收应付账户。缺少对方、多方无法确定、符号方向或本金金额不一致会进入预检错误列表。借贷查重使用发生时间、金额、借贷种类和转出／转入账户，不能把不同对方的同秒同额流水误判为重复。

拾光导出双边账户时，对含逗号、冒号或引号的账户名使用 JSON 字符串引用；再次导入会还原原名。普通未引用的挖财名称仍兼容，单账户名称自带冒号不会因此被当作双边流水。

## WebDAV / S3

云备份完全由用户主动启用。应用会把完整 `.skbak` 文件上传至用户配置的目录或存储桶；删除远端文件前必须二次确认。

- 坚果云使用 `https://dav.jianguoyun.com/dav/`、账号邮箱和第三方应用密码，不要填写登录密码。
- Android WebDAV 通道要求 HTTPS；单个文件最大 50 MB，超限时请使用本地备份。不会自动跟随重定向，请填写最终服务器地址。
- “测试连接”只读取目录；目录不存在时先验证服务器根地址，首次上传再创建目录。
- 浏览器/PWA 直连要求服务器允许跨域。坚果云不支持此方式，请使用 Android 版；应用不通过公共代理转发凭据。

## QQ 邮箱备份

仅 Android 支持。在「云端备份」选择「QQ 邮箱」，填写发件邮箱、QQ SMTP 授权码和收件邮箱。应用直接通过 `smtp.qq.com:465` 的 TLS 连接发送，无需部署邮件服务；网页版不提供邮箱入口。WebDAV/S3 配置仍保留，切换通道即可使用。

- 先在 QQ 邮箱设置中启用 SMTP，生成 16 位授权码。「保存并测试」仅验证 SMTP 登录，不发送邮件。实际发送前展示发件及收件邮箱，再输入至少 8 位备份口令并确认。
- 发送完整加密 `.skbak`，单份最大 10 MB。口令不发送、不保存；授权码由 Android Keystore 加密保管，不进入备份。备份文件过大时改用云盘或本地备份。
- 「邮件服务器已接收」表示 SMTP 接收，不能代表邮箱已投递；检查收件箱、垃圾邮件及退信。应用持久保存请求状态，已接受的同一请求不会重复发送；结果不确定时禁止自动重发，先检查邮箱，不连续重新生成发送。
- 下载邮件附件后在「备份与恢复」中选择文件，支持口令校验、恢复前快照和事务化替换。此功能不读取邮箱内容，也不自动定时发送。

## 备份历史与恢复

「备份与恢复」合并历史记录与文件选择入口。新生成的本地、WebDAV/S3 和邮箱备份会在本机保留一份实际文件，点击记录旁的「恢复」即可开始校验；加密文件仍需口令，用户确认后才替换账本。也可以随时点击「选择备份文件」。

本机最多保存最近 10 份副本、合计 100 MB，超过限制会淘汰较早副本；空间不足或单份超限时不缓存，但不影响已经完成的导出、上传或发送。旧记录或副本已淘汰时显示「选文件」。副本存放在独立数据库，不打包进新备份，也不会被恢复旧账本清空；卸载或清除应用数据可能删除这些副本，请另存文件。

恢复和导入前的可撤销快照仍保留 7 天。备份提醒已移除，包括设置、首页提示和 Android 排期；旧版设置不再生效，应用启动时会取消旧的备份通知。
