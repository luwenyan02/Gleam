# v1.3.2 本地交付验收

日期：2026-09-07。范围：用户反馈的首页数字、借贷方向、转账交换与 AI 平台模型目录。不宣称整个产品已完成真机验收。

## 已验证

- 首页：普通数字字形，统一单位为元，三项辅助金额对齐；360/390/430px、桌面截图检查。
- 借贷：借出和还款为账户 → 对象，借入和收款为对象 → 账户；DOM 焦点顺序一致，切换保留已选对象。
- 转账：鼠标点击、键盘 Enter 可交换账户；金额和备注保留；保存后的转出／转入 ID 和整数金额正确。
- AI：近期日期筛选、每平台最多 10 个候选、当前配置保留、已知文本模型的图片拦截、缓存接口隔离通过测试；完整名称在四种屏宽可读。
- 模拟 API 流程验证百炼 Qwen、OpenAI GPT 的请求参数以及获取模型后的十条上限和缓存隔离；未调用真实付费服务。
- 完整 8 组浏览器回归通过。独立审查发现的采样参数范围问题修正后，27 项单元测试及四屏宽模型流程再次通过；独立复核无阻断项。
- 生产构建、敏感信息扫描和补丁格式检查通过。
- Android 候选包使用原证书；原生／网页版本均为 1.3.2，20 个内嵌网页文件与最终 dist 逐字节一致。
