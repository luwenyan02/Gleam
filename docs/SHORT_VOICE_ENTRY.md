# 手机短语音记账

## 实施范围

本页介绍单笔短语音记账：阿里云百炼转写声音，文字模型生成草稿，由用户核对保存。Android 使用个人自带 Key 的原生通道，不归档录音、不自动保存多笔账目。首页长按「+」或收件箱中的按住说话发起录音，松开发送触发本次解析；「记一笔」麦克风入口保留文字核对后发送。持续对话另见 [实时语音说明](REALTIME_VOICE.md)。

历史记录：v1.10.7 私有候选基于已交付的 v1.10.6（PR #14，`1123840`），当时仅精简连接测试和调整草稿操作布局，未修改模型或原生协议。最终浏览器、安装包及手机验收状态以交付记录为准。

## 手机设置与使用

1. 「我的 → 设置」中，填写「百炼短语音」服务地域和业务空间 ID；语音Key可勾选「与 API Key 相同」或单独填写。当前固定支持 `qwen3.8-omni-flash-realtime`；Key 必须与地域、空间一致，账号需具备模型权限。
2. 点「测试语音连接」明确发起一次无录音测试，测试中同一按钮可取消。只有成功且候选仍有效，才一并提交 Key、来源和配置；失败或取消不替换原生效配置。结果使用轻提示，连接成功不代表录音已经测试。
3. 语音Key只进入本机 Android Keystore 加密存储，不以原文读回设置框、不进入普通备份、Git 或安装包；首尾掩码不是可提交的凭据。共享主 Key 变化后须重新测试，既有独立 Key 不自动切换来源。
4. 首页长按「+」直接在流水上打开语音蒙层，先显示「正在准备语音」，看到「正在听」后说话；实时显示百炼中间转写，发送区仅使用最终转写进行账单识别。手指滑到取消／编辑会高亮并按系统设置反馈触感，移回下方可继续说，松手按所处区域执行。滑选「编辑文字」立即停止录音，带入当时显示的文字打开短语音编辑框；无文字也可进入手填，只有点发送才调用文字 AI。等待最终转写时仍可点「编辑文字」，立即带入当前文字手改。编辑框右上角「退出」关闭蒙层。发送区空语音关闭，有文字则松手后自动识别：有效单笔在草稿准备好后直接切换到编辑页，准备期间仍可取消／编辑；读取失败保留文字供重试。信息不足则保留文字供修改重发。点「重新录音」清空旧文字，再按住下方按钮说话，沿用同一套滑选手势。
5. 「AI 记账收件箱 → 语音记账」先进入待机，再按住说话；松开、滑选编辑／取消和重录与首页一致。识别成功直接打开草稿供人工保存。首次录音需允许系统麦克风权限，数据接收方和可能费用见设置与使用手册。
6. 「记一笔」麦克风入口打开短语音浮层，点「开始说话」，说一句普通支出／收入，在30秒内点「说完了」。可取消、修改转写文字或直接手填；超限不会自动提交。
7. 「记一笔」浮层中，转写或手填后点「发送并生成草稿」才调用文字 AI；可重新录音或填入当前草稿，核对后保存。首页和收件箱共用按住说话流程，不额外生成语音队列卡。

网页版不接收或保存百炼语音 Key，没有系统语音服务回退；可在同一浮层手填文字。原有开发网页版生活实时语音仍是独立能力，见 [REALTIME_VOICE.md](REALTIME_VOICE.md)。

## 历史基线（v1.9.0，非当前功能状态）

以下为接入前的核对记录（`5e01b3a`）：

- 「记一笔」已有浏览器 SpeechRecognition 麦克风按钮，但只用本地正则填入金额、分类和备注；不是 Android 原生识别，也没有复用 AI 收件箱

- AI 收件箱已有查重、整数分、原子导入和人工编辑能力，但允许高置信度自动入账；短语音必须始终人工确认

## 交互与数据边界

1. 仅打开既有麦克风／收件箱浮层不录音；首页长按「+」和重录按钮的按住动作明确发起录音。底层流水与账本保持不动
2. 服务、地域与费用说明见设置和使用手册；用户主动开始或长按后才申请麦克风并发送，录音最长 30 秒。权限、建连和转写分别有独立超时，前端保底等待95秒不会挤占录音窗口
3. 转写文字可修改、取消或改用手动输入。拾光不保存音频文件
4. AI 识别使用本次文字、已配置接口/模型和候选分类/账户名称的本机快照。首页松开发送或编辑页点发送作为本次解析授权；其他入口保留核对文字再发送。只发送这些内容及识别规则，不发送旧账单、余额、生活记录、照片或历史聊天
5. 只处理一笔普通支出/收入。转账、借贷、信用卡还款、退款与报销使用已有完整手动账务，不能降级成普通支出/收入
6. 识别结果只形成可核对草稿；金额、分类、账户、时间、备注仍由用户核对保存。进入收件箱的语音草稿不能被自动确认阈值绕过

### 既有麦克风／收件箱入口的简化交互

- 同意后立刻显示准备动画；只有原生 `listening` 事件到达才显示「正在听」与节奏条。转写时显示独立等待状态，停止按钮只在录音时出现。动画仅代表状态，不代表实际音量；遵循减少动态效果设置，读屏通过文字状态获知进度。
- 录音过程中隐藏非当前步骤的表单与说明；转写后收起录音提示，保留「重新录音」入口，重新录音仍需再次同意。
- 自动准备仅调用本机预览逻辑；编辑立即撤销旧预览，输入法组合期间不准备半成品。取消、返回、配置变化和迟到结果都不能恢复过期同意或自动生成账单。
- 设置页保留 Key 状态、连接测试结果；安全存储与使用说明移到可展开区域。

取消、关闭、后台/来电中断、超时、权限拒绝、重复点击和迟到回复均结束当前会话。旧会话不能覆盖新文字或新账单；重复保存仍遵循现有原子保存与查重边界。百炼接收声音并按其服务规则处理，可能产生模型费用；文字接口的单次确认另行进行，声音不会通过文字接口发送。

首页蒙层使用 [服务端事件](https://help.aliyun.com/zh/model-studio/server-events) 中的 `conversation.item.input_audio_transcription.delta`，按 `text + stash` 替换实时预览而非累加；预览不直接生成账单；滑选编辑可带入当前可见文字供手工修正和明确发送，不改变 Manual 配置、提交与最终转写的校验。最多 500 字，按当前会话和 item 隔离；退出、后台、设置变化与取消后忽略迟到文字和 AI 结果。波形为录音状态动画，不代表测量音量。

## Android 接入核查

百炼实时模型支持 Android；早期安装包的限制是没有打包 Vite 的本机中转；当前 Android 已使用原生通道，短语音与语音聊均无需该中转。[Realtime API 概述](https://help.aliyun.com/zh/model-studio/realtime-api-overview)列出 AOQ 的 Android 支持、WebRTC 的移动端支持以及 WebSocket 的全平台支持。

百炼 [WebRTC 接入](https://help.aliyun.com/zh/model-studio/realtime-webrtc-access)推荐由业务 AppServer 代理 SDP，避免长期 API Key 放在前端。[AOQ Android 实时语音示例](https://help.aliyun.com/zh/model-studio/real-time-voice-conversation-using-aoq-access-qwen-audio-3-0-realtime-plus)提供按连接生成凭证的方式。本阶段选择个人自带 Key 的原生安全直连，不内置共享长期 Key，也不部署额外后端。

本阶段使用 WebSocket Manual：16kHz、16-bit little-endian 单声道 PCM，收到 `session.updated` 并核对文本输出、Manual、转写模型及音频格式后才打开麦克风。「说完了」或首页松手提交输入，只接受对应本次 item 的最终输入转录；不发送 `response.create`，不启用模型语音播报、工具或联网搜索。[客户端事件](https://help.aliyun.com/zh/model-studio/client-events)与[服务端事件](https://help.aliyun.com/zh/model-studio/server-events)是协议依据。

[Qwen-Omni 文档](https://help.aliyun.com/zh/model-studio/realtime)明确 WebRTC 仅支持服务端 VAD，不能直接改成 Manual。原生域名由北京/新加坡与安全的空间 ID 推导，固定 WSS/TLS；不接受任意 URL、重定向、不安全证书或第三方回退。凭据修改/清除、权限迟到、重复启动、页面后台、音频焦点/来电和设备录音静默都会隔离或取消会话。Capacitor 桥日志在 debug/release 都关闭，避免写入 Key 参数。

## 验收

开发与 CI 仅使用合成文字、模拟识别器及模拟网络，不采集真实麦克风、不调用付费服务、不引入凭据。需覆盖权限/取消/后台/超时/重复/迟到、手改文字、单笔与特殊账务拒绝、一次性授权、整数分与强制人工确认；保留既有账务评测 oracle。

浏览器在 360、390、430px 和桌面 PWA 验收。Android 编译与单元测试不能替代真机服务兼容性、麦克风权限、来电中断或安装升级验收；实际完成状态必须分别记录。
