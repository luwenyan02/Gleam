# v1.10.2 私有语音诊断候选包

基线为正式 v1.10.0（f70eb46b1edad54c7e5332ac96670320d7467059）。本分支不包含消费节奏卡，未经真机验证，不合并 main 或发布正式 Release。

## 第二轮诊断

用户已在1.10.1复现 SPEECH_PROTOCOL、确认配置阶段。本轮在保持安全核验的前提下增加固定失败原因枚举，区分回显字段缺失、类型/值不匹配及消息解析问题；只传预定义诊断枚举，不输出实际服务响应值。具体根因仍需手机返回的细项确认，不宣称已修复。

## 本次修正

- 短语音失败保留固定安全错误码和失败阶段；不显示服务商原始错误正文、凭据、录音或历史内容。
- 设置增加单独的连接测试；保存 Key 仍只写本机安全存储，不调用服务。
- 用户先预览百炼地域、业务空间域名和模型及可能费用，再主动同意一次测试。
- 测试只建连、验证鉴权和会话配置；不申请麦克风，不创建录音器，不发送音频、账单或模型生成请求。配置确认后立即关闭。
- 测试成功只代表本次连接和配置通过，不代表麦克风或实际转写可用。
- 输入变动、Key 变更、导航、后台、取消和超时会撤销本次测试，迟到结果不恢复成功，不自动重试或开启录音。

## 构建与安全

版本号1.10.2（Android11002）仅用于让已安装1.10.0的用户辨认测试包。遵循原 F979…0012 完整证书，不生成新签名。

为通过安全检查，本分支仅复用之前已批准的锁文件升级：@capacitor/android8.5.0→8.5.1、source-map-js1.2.1→1.2.2。协议解析 JVM 测试新增 testImplementation org.json:json:20240303，不改变运行时依赖。

正常 release 构建仍要求原签名配置。CI 只有显式使用 -PgleamUnsignedTestApk=true 才生成无签名测试产物；产物与同次 dist 仅作为私有短期 artifact 保留3天。该文件不能直接交付安装。下载后在获授权构建环境用原签名签署，再核验唯一签名者、版本和全部网页字节；私钥及口令不进入 CI、Git、artifact、日志或安装包。

## 验证范围

开发、单元和浏览器验收使用虚构配置/文本与模拟原生桥，不调用真实百炼或麦克风。最终实际结果、CI提交及校验值另随候选包提供；未完成项目不得标记通过。

安装测试前建议保留应用之外可用的加密备份。请先在设置测试连接并查看阶段/错误码；连接通过后再用短语音入口单独同意实际转写。系统授权、设备音频占用、真机后台/来电及服务兼容性仍需手机验收。
