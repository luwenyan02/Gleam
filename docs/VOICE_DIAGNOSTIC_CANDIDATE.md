# v1.10.4 私有短语音交互候选包

基线为正式 v1.10.0（f70eb46b1edad54c7e5332ac96670320d7467059）。本分支不包含消费节奏卡，不合并 main 或发布正式 Release。用户已确认 v1.10.3 连接测试和记一笔短语音可用；v1.10.4 新交互仍待手机验收。

## 第四轮交互优化

精简常驻说明，录音状态动画区分准备、正在听和转写，并遵循减少动态效果。转写/手填后自动准备本地预览，减少一次点击；声音发送、文字 AI 发送和账单保存的人工确认边界保留。修复异步配置读取与后台编辑防抖的过期状态问题，详情见 [短语音交互](SHORT_VOICE_ENTRY.md)。

## 第三轮限定兼容修复（v1.10.3 历史）

用户在1.10.2确认唯一失败原因为 ACK_TURN_DETECTION_MISSING。本轮保留无上下文的严格 safeAck，仅在当前连接已成功发送唯一、明确 turn_detection:null 的固定手动配置后，依据 session.updated 的成功语义兼容缺失回显；不是把任何缺失字段视为 null。显式 VAD、类型错误或矛盾配置仍拒绝，其他核验保留。此兼容依赖服务端协议契约，不能独立证明实际 VAD 已关闭，仍待真机验收。

依据：[官方最小 WebSocket Manual 示例](https://help.aliyun.com/zh/model-studio/realtime)发送明确 null 后等待 session.updated；[服务端事件规范](https://help.aliyun.com/zh/model-studio/server-events)规定成功更新返回 session.updated、失败返回 error。Omni 文档未明确保证禁用字段一定省略。

## 第二轮诊断

用户已在1.10.1复现 SPEECH_PROTOCOL、确认配置阶段。本轮在保持安全核验的前提下增加固定失败原因枚举，区分回显字段缺失、类型/值不匹配及消息解析问题；只传预定义诊断枚举，不输出实际服务响应值。具体根因仍需手机返回的细项确认，不宣称已修复。

## 本次修正

- 短语音失败保留固定安全错误码和失败阶段；不显示服务商原始错误正文、凭据、录音或历史内容。
- 设置增加单独的连接测试；保存 Key 仍只写本机安全存储，不调用服务。
- 用户先预览百炼地域、业务空间域名和模型及可能费用，再主动同意一次测试。
- 测试只建连、验证鉴权和会话配置；不申请麦克风，不创建录音器，不发送音频、账单或模型生成请求。配置确认后立即关闭。
- 测试成功只代表本次连接和配置通过，不代表麦克风或实际转写可用。
- 输入变动、Key 变更、导航、后台、取消和超时会撤销本次测试，迟到结果不恢复成功，不自动重试或开启录音。

## 构建与安全

版本号1.10.4（Android11004）仅用于让已安装1.10.0的用户辨认测试包。遵循原 F979…0012 完整证书，不生成新签名。

为通过安全检查，本分支仅复用之前已批准的锁文件升级：@capacitor/android8.5.0→8.5.1、source-map-js1.2.1→1.2.2。协议解析 JVM 测试新增 testImplementation org.json:json:20240303，不改变运行时依赖。

正常 release 构建仍要求原签名配置。CI 只有显式使用 -PgleamUnsignedTestApk=true 才生成无签名测试产物；产物与同次 dist 仅作为私有短期 artifact 保留3天。该文件不能直接交付安装。下载后在获授权构建环境用原签名签署，再核验唯一签名者、版本和全部网页字节；私钥及口令不进入 CI、Git、artifact、日志或安装包。

## 验证范围

开发、单元和浏览器验收使用虚构配置/文本与模拟原生桥，不调用真实百炼或麦克风。最终实际结果、CI提交及校验值另随候选包提供；未完成项目不得标记通过。
