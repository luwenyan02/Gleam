## 复现

安装项目依赖和 Playwright Chromium 后，在 `app/` 目录构建，并运行完整浏览器检查：

```sh
npm run build
npm run test:e2e
```

完整运行及CI的第1分片在回归结束后执行 [capture_readme.py](../../../app/e2e/capture_readme.py)。输出放在仓库根目录 `.tmp/tests/e2e/readme/<宽度>/`，不会直接覆盖本目录。

已有独立生产预览服务时，也可以单独生成截图：

```sh
GLEAM_E2E_URL=http://127.0.0.1:4617/ python3 e2e/capture_readme.py
```

语音展示截图单独生成（使用同一个生产预览服务）：

```sh
GLEAM_E2E_URL=http://127.0.0.1:4617/ python3 e2e/capture_voice_readme.py
```

更新时先检查实际图片，确认版本、页面完整性、数据来源与浮层状态，再复制选定PNG并更新校验值。历史截图与来源可通过 Git 历史查看。
